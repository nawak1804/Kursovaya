# Japan Trip Planner

Новая версия интерфейса включает:
- liquid glass стиль,
- часы MSK/JST + компас,
- расширенный виджет радио (много РФ станций, prev/next, громкость, эквалайзер),
- реклама (боковая, нижняя широкая, fullscreen напоминания),
- математическая проверка при закрытии рекламы (случайно),
- счётчик Гейгера с усилением при наведении на крестик рекламы,
- индикатор «зомби-заражения» внизу,
- комментарии, оценки, общий рейтинг,
- обои (пресеты + пользовательская загрузка),
- снежинки сверху и реакции-эмодзи снизу,
- уведомления каждые 5 секунд (звук можно отключить).

## Запуск
```bash
python3 -m http.server 8000
```
Открыть: `http://localhost:8000`
