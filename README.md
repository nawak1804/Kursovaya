# Japan Trip Planner

В этой версии восстановлено и работает одновременно:
- адаптивная календарная лента (горизонтальный скролл карточек дней в рамках экрана),
- задачи дня + режим «таймлайн по часам»,
- расширенный радио-виджет (станции РФ, prev/next, play/pause, громкость, эквалайзер),
- часы MSK/JST, компас и геолокация,
- счётчик Гейгера (динамика + всплеск при наведении на крестик рекламы + звук),
- онлайн-счётчик пользователей (400–600),
- уведомления каждые 5 секунд с отключаемым звуком,
- агрессивные рекламные блоки + math-челлендж при закрытии,
- зомби-индикатор заражения с перезапуском,
- снежинки и эмодзи-реакции,
- настройки фона/стиля (пресеты + загрузка своего фона),
- история действий и Undo/Redo.

## Запуск
```bash
python3 -m http.server 8000
```
