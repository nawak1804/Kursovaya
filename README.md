# Japan Trip Planner

Рабочая версия включает:
- календарную ленту + задачи дня,
- режим «таймлайн по часам»,
- радио-виджет (список станций РФ, prev/next, play/pause, громкость, эквалайзер),
- часы MSK/JST, компас, счётчик Гейгера,
- онлайн-счётчик пользователей 400–600,
- уведомления каждые 5 секунд (звук отключаемый),
- агрессивные рекламные виджеты + математика при закрытии,
- зомби-индикатор заражения,
- комментарии и общий рейтинг,
- снежинки и эмодзи-реакции.

## Запуск
```bash
python3 -m http.server 8000
```
